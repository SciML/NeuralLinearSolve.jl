NeuralLinearSolve.jl: Neural Network-Based Linear Solver Selection

NeuralLinearSolve.jl uses a pretrained convolutional neural network (CNN) to predict the fastest linear solver for a given sparse matrix. The sparse matrix is converted to a 64x64 spy plot image, which is fed into the CNN to predict the optimal solver from UMFPACK, KLU, and Pardiso.

Installation

To install NeuralLinearSolve.jl, use the Julia package manager:

using Pkg
Pkg.add("NeuralLinearSolve")

Quick Start

using NeuralLinearSolve
using SparseArrays

A = sprand(1000, 1000, 0.01)

# Get the predicted fastest solver
solver = predict_solver(A)

# Get the full probability distribution over solvers
probs = predict_solver_probs(A)

API

NeuralLinearSolve.predict_solver — Function
predict_solver(A::SparseMatrixCSC) -> Symbol

Predict the linear solver expected to be fastest for a sparse matrix.

The bundled convolutional neural network converts A into a fixed-size sparsity image and selects one of the supported solver labels. The model is loaded on the first call and then cached for subsequent predictions.

Arguments

  • A: Sparse matrix whose sparsity pattern is used for the prediction.

Returns

  • Symbol: A predicted solver label, currently one of :UMFPACK, :KLU, or :Pardiso.

Examples

julia> using NeuralLinearSolve, SparseArrays

julia> A = sprand(16, 16, 0.2);

julia> predict_solver(A) in (:UMFPACK, :KLU, :Pardiso)
true
source
NeuralLinearSolve.predict_solver_probs — Function
predict_solver_probs(A::SparseMatrixCSC) -> Dict{Symbol, Float32}

Predict the probability assigned to each supported linear solver for a sparse matrix.

The probabilities are produced by the same cached model used by predict_solver and are useful when downstream code needs to choose among close predictions.

Arguments

  • A: Sparse matrix whose sparsity pattern is used for the prediction.

Returns

  • Dict{Symbol, Float32}: A mapping from each supported solver label to its predicted probability.

Examples

julia> using NeuralLinearSolve, SparseArrays

julia> A = sprand(16, 16, 0.2);

julia> probs = predict_solver_probs(A);

julia> isapprox(sum(values(probs)), 1f0)
true
